✨ Overview

A dynamic, interactive 3D character portfolio slider built entirely with vanilla HTML, CSS, and JavaScript — no frameworks, no libraries. Designed with assets sourced and hosted via Figma, it features a high-impact toon-style 3D carousel used as a personal UI/UX developer showcase.
