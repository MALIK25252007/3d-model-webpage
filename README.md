# 🎭 3D Model Character Showcase Portfolio

An interactive, visually dynamic portfolio landing page built using **HTML5, CSS3, and JavaScript**. This project showcases 3D cartoon avatar models with smooth slide transitions and dynamic theme color changes driven by state updates.

---

## ✨ Features

* **Dynamic Theme Switching:** The background theme automatically adjusts hex colors to complement the active 3D model asset.
* **Interactive Slider:** Navigation buttons allowing smooth switching between cartoon character avatars.
* **Figma Asset Integration:** Hosted external assets directly linked for clean, modular image management.
* **Responsive Layout:** Clean typography, minimalist UI elements, and modern bold backdrop text ("3D MODEL").

---

## 🛠️ Tech Stack

* **HTML5:** Semantic page structure and controls.
* **CSS3:** Modern styling, positioning, flexbox, and typography.
* **JavaScript (ES6):** Dynamic DOM manipulation, array iteration for images, and color-theme state management.
* **Figma:** Visual asset sourcing and design prototyping.
